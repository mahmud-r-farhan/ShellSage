# Go Menu Viewer

A fun interactive terminal app built with Go. Select categories and explore information!

## Features

- Category-based CLI interaction
- JSON-powered data
- Interactive navigation

## Run Locally

```bash
git clone https://github.com/mahmud-r-farhan/go-menu-viewer
cd go-menu-viewer
go run main.go
```

### Run the app
```bash
go run main.go
```

### Optionally, build the binary


```bash
go build
./go-menu-viewer
```
